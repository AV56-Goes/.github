# AV'56 Goes

Athletics club in Goes, Zeeland (the Netherlands), since 1956. Youth, seniors, masters and nordic walkers train at
Sportpark Het Schenge, and the club organises races such as the Sasloop.

*Atletiekvereniging AV'56 uit Goes, sinds 1956. Wil je meedoen? Kom een keer [proeftrainen](https://av56.nl/proeftraining).*

## Our websites

- **[av56.nl](https://av56.nl)**: the club's site, with news, training, events, results, records and photos.
- **[zeeuwseranglijsten.nl](https://zeeuwseranglijsten.nl)**: the Zeeland athletics rankings, kept for the clubs in
  Zeeland, with results back to 1953.

## On GitHub

The code of both sites lives here. Volunteers of the club built and maintain it.
